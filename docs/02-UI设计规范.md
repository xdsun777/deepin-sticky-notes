# Deepin 极简便签 App — UI 设计规范

> 版本：v1.0  
> 设计原则：极简、低打扰、原生质感，遵循 Deepin 人机交互设计语言

---

## 二、字体

- 字体族：`"Noto Sans CJK SC", "WenQuanYi Micro Hei", "Ubuntu", sans-serif`
- 正文字号：**14px**，行高 1.5
- 强调文字：15px / Medium
- 菜单文字：13px
- 已完成待办：删除线 + opacity 0.6

---

## 三、布局与尺寸

| 项 | 值 |
|---|---|
| 窗口圆角 | 8px |
| 窗口内边距 | 16px（四周） |
| 行间距 / 块间距 | 8px |
| 默认窗口尺寸 | 280 × 360 |
| 最小窗口尺寸 | 200 × 200 |
| 右上角按钮 | 直径 12px，间距 6px，距边距 8px |
| 复选框 | 16 × 16px，与文字水平间距 8px |
| 拖拽手柄 | 右下角 4px 对角线，hover 显示 |

---

## 四、阴影与层级

- 便签窗口：`0 4px 16px rgba(0,0,0,0.15)`
- 色板 / 菜单浮层：`0 2px 8px rgba(0,0,0,0.12)`
- 置顶窗口阴影加深一档：`0 8px 24px rgba(0,0,0,0.2)`

---

## 五、动效

| 动作 | 曲线 / 时长 |
|---|---|
| 窗口显示 / 隐藏 | ease, 150ms |
| 主题切换过渡 | ease, 200ms |
| 色板弹出 | scale 0.9→1 + fade, 150ms |
| 待办勾选 | 对勾 scale 0→1, 100ms |
| 置顶按钮切换 | 颜色过渡 200ms |

---

## 六、控件状态

- 按钮 hover：背景填充半透明灰，圆角 50%（圆形按钮）
- 复选框 hover：边框变为勾选色，粗细不变
- 可拖拽手柄 hover：颜色加深，提示可交互
