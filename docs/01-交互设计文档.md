# Deepin 极简便签 App — 交互设计文档

> 版本：v1.0  
> 技术栈：Rust + Slint  
> 目标平台：Deepin Linux V23

---

## 一、全局启动与退出

| 操作 | 反馈 |
|---|---|
| 双击图标启动 | 托盘出现图标；桌面恢复上次所有便签的位置与内容 |
| 关闭任意便签窗口 | 窗口 fade 隐藏，进程不退出，数据保留 |
| 托盘右键 → 退出 | 写入当前状态后终止进程 |
| 重启应用 | 从 JSON 恢复全部便签（位置、大小、置顶、内容、底色） |

---

## 二、便签窗口交互

| 操作 | 交互细节 |
|---|---|
| 移动窗口 | 按住空白区域拖拽；无边框设计，无独立标题栏 |
| 缩放 | 右下角拖拽手柄（hover 时显示 4px 对角线）；最小 200×200 |
| 置顶切换 | 点击右上角图钉图标；激活时图钉高亮、窗口层级提升 |
| 切换底色 | 点击调色板图标，弹出 3 色圆点色板（浅黄 / 白 / 浅蓝），选中即切换 |
| 关闭便签 | 点击 X，窗口隐藏；再次从托盘"显示全部"唤回 |
| 新建便签 | 托盘菜单 / 双击托盘图标 / `Ctrl+Alt+N`；新便签出现在屏幕中心偏右 |

---

## 三、内容编辑交互（文本 + 待办混合）

| 操作 | 交互细节 |
|---|---|
| 输入文本 | 直接键入，自动防抖保存（500ms 无操作后落盘） |
| 插入待办行 | 右键菜单 → "插入待办项"，或在空行输入 `- [ ]` 自动转为复选框 |
| 勾选待办 | 点击复选框，对勾淡入 100ms，文字自动加删除线、透明度降至 60% |
| 取消勾选 | 再次点击，删除线与透明度恢复 |
| 删除待办 | 待办行按退格清空文字后，自动降级为普通文本行（不残留空复选框） |
| 调整顺序 | 待办条目左侧出现拖拽手柄，上下拖拽重排；文本块不可拖拽 |
| 右键菜单 | 复制 / 粘贴 / 全选 / 插入待办项 |
| 多行选中 | 支持 Shift 多选块；删除整块时整块移除 |

---

## 四、托盘交互

| 操作 | 反馈 |
|---|---|
| 左键单击托盘图标 | 切换"全部显示 / 全部隐藏" |
| 右键托盘图标 | 弹出菜单：新建便签（Ctrl+Alt+N）/ 显示全部 / 隐藏全部 / ─── / 退出 |

---

## 五、主题交互

- 无手动切换入口，完全跟随 Deepin 系统亮 / 暗主题
- 系统切换主题时，所有已打开便签 200ms 内平滑过渡配色
- 监听方式：`gsettings` 或 DDE 配置键变化事件
