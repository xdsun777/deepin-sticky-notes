# Deepin 极简便签 — 用户使用手册

> 技术栈：Rust + Slint（winit + femtovg 后端）
> 目标平台：Deepin Linux V23

一款轻量、低打扰的桌面便签应用：多便签窗口、文本与待办混合编辑、Markdown 渲染、置顶、系统托盘与全局热键，配色完全跟随系统主题（也可手动切换）。

## 一、运行与安装

### 开发运行

```bash
cd deepin-sticky-notes
cargo run
```

### 编译发布版

```bash
cargo build --release
```

### 打包为 .deb

```bash
cargo deb
```

生成的 `.deb` 会安装：可执行文件（`/usr/bin`）、桌面启动项、登录自启项（`/etc/xdg/autostart`）和图标。

### 首次启动

首次启动会自动创建一个空白便签；之后每次启动都会从磁盘恢复上次所有便签的位置、大小、置顶状态和内容。

## 二、便签窗口操作

便签为无边框窗口，右上角四个圆形控制按钮（从左到右）：

| 按钮 | 图标 | 作用 |
|---|---|---|
| 主题切换 | ☀ / ☾ | 手动切换浅色 / 深色（见 [主题切换](#六主题切换)） |
| 置顶 | 图钉 | 切换窗口置顶，激活时高亮为蓝色 |
| 删除 | 垃圾桶 | 永久删除该便签（hover 变红警示） |
| 关闭 | ✕ | 隐藏该便签，数据保留，进程不退出 |

| 操作 | 方法 |
|---|---|
| **移动窗口** | 按住便签空白区域（标题栏一带）拖拽 |
| **缩放窗口** | 从便签边缘 / 四角向外拖拽（最小 200×200） |
| **新建便签** | `Ctrl+Alt+N` / 托盘双击 / 托盘右键菜单 |

> 关闭（✕）与删除（垃圾桶）的区别：关闭只是隐藏，可从托盘「显示全部」唤回；删除是永久移除并落盘。

## 三、内容编辑

便签内容由「文本块」和「待办块」混合组成：

- **文本块**：多行段落，回车换行。
- **待办块**：单行，左侧带复选框与拖拽手柄。

| 操作 | 方法 |
|---|---|
| 输入文字 | 直接键入，500ms 防抖自动保存 |
| **换行** | 文本块内按 `Enter` |
| 在待办块按 `Enter` | 在下方新建一个文本块 |
| **插入待办** | 右键菜单「插入待办项」，或在空行输入 `- [ ]` 自动转换 |
| **勾选待办** | 点击复选框（对勾 100ms 淡入 + 文字删除线、透明度降至 60%） |
| **取消勾选** | 再次点击复选框 |
| **删除待办** | 清空文字后按 `退格` → 自动降级为普通文本行 |
| **删除文本块** | 清空文字后按 `退格` → 删除该块 |
| **调整待办顺序** | 按住待办左侧「≡」手柄上下拖拽重排 |
| **多选删除** | 点击最左侧选择槽选中；`Shift`+点击扩展选区；右键「删除本行」整段移除 |
| **右键菜单** | 复制 / 粘贴 / 全选 / 插入待办项 / 删除本行 |

## 四、Markdown 支持

点击文本块进入**编辑态**（显示原始 Markdown 源码），点击别处后进入**预览态**（显示渲染结果）。

| 语法 | 效果 |
|---|---|
| `**加粗**` | **加粗** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `` `代码` `` | 行内代码 |
| `[文字](https://…)` | 蓝色可点击链接 |
| `- 项目` | 无序列表 |
| `1. 项目` | 有序列表 |

> 以下语法当前**不支持**（会回退为原文显示）：`# 标题`、``` 代码块 ```、表格、引用、任务列表 `- [ ]`、图片。这是 Slint 内置渲染器的限制。

## 五、系统托盘

应用启动后托盘出现便签图标：

| 操作 | 效果 |
|---|---|
| **左键单击** | 切换「全部显示 / 全部隐藏」 |
| **左键双击** | 新建便签 |
| **右键菜单** | 新建便签（Ctrl+Alt+N）/ 显示全部 / 隐藏全部 / ─── / 退出 |

> 退出会先写入当前全部状态，再终止进程。

## 六、主题切换

- 默认**完全跟随系统**亮 / 暗主题，系统切换时所有便签 200ms 内平滑过渡配色。
- 点便签右上角 **☀/☾ 按钮**可**手动切换**全局浅 / 深色：
  - 浅色模式显示 ☀，深色模式显示 ☾；
  - 手动切换后不再跟随系统；
  - **重启应用后恢复跟随系统**。

---

## 七、数据存储

- 路径：`~/.local/share/deepin-sticky-notes/notes.json`（符合 XDG Base Directory 规范）。
- 保存时机：内容 / 置顶 / 尺寸 / 位置变化后 500ms 防抖落盘；退出时强制 flush。
- 恢复内容：位置、大小、置顶状态、全部文本与待办块。

## 八、已知限制

| 项 | 说明 |
|---|---|
| 块级 Markdown | 标题 / 代码块 / 表格 / 引用不渲染（见上文） |
| 待办拖拽排序 | 在含多行块时目标位置估算略有偏差（单行块场景精确） |
| `- [ ]` 自动转换 | 仅当整个文本块内容恰好为 `- [ ]` 时触发；多行块内请用右键菜单插入待办 |
| 纯 Wayland 无 XWayland | 新建便签「屏幕中心偏右」退化为左上角级联；全局热键可能失效（可用窗口内 `Ctrl+Alt+N` 兜底） |
| 托盘双击 | `tray-icon` KSNI 后端在 Linux 不产生双击事件，由 350ms 窗口手动判定 |
