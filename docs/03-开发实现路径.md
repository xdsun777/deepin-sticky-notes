# Deepin 极简便签 App — 开发实现路径

> 版本：v1.0  
> 技术栈：Rust + Slint  
> 目标平台：Deepin Linux V23

---

## 一、技术栈

- Rust 2021 edition，Slint 1.9+（winit + femtovg 后端）
- 系统托盘：`tray-icon`
- 全局热键：`global-hotkey`
- 序列化：`serde` + `serde_json`
- 路径：`directories`（XDG 规范）
- 错误处理：`anyhow`

## 三、核心数据模型

```rust
enum BlockType {
    Text,
    Todo,
}

struct Block {
    id: String,
    block_type: BlockType,
    content: String,
    checked: Option<bool>,   // 仅 Todo 使用
}

enum NoteColor {
    Yellow,
    White,
    Blue,
}

struct Note {
    id: String,
    position: (i32, i32),
    size: (u32, u32),
    always_on_top: bool,
    color: NoteColor,
    blocks: Vec<Block>,
}
```

## 四、分阶段开发计划

### Phase 1 — 基础框架（1~2 天）
- Cargo 项目初始化，集成 Slint
- 单窗口便签，纯文本编辑框
- JSON 持久化读写（启动加载 / 退出保存）

### Phase 2 — 多窗口 + 托盘（2~3 天）
- 多 Note 窗口实例管理（HashMap<id, Window>）
- `tray-icon` 集成：菜单、左键切换
- 窗口拖拽移动、右下角缩放、置顶切换

### Phase 3 — 混合编辑器（3~4 天）
- Block 列表模型，Slint 中用条件渲染区分 Text / Todo
- 复选框交互、删除线、自动降级为文本
- 待办拖拽排序
- 右键菜单

### Phase 4 — 主题与打磨（1~2 天）
- 监听 DDE 主题键，切换亮 / 暗配色变量
- 三色色板弹出与切换
- `Ctrl+Alt+N` 全局热键
- 动效与 hover 状态补全

### Phase 5 — 打包部署（1 天）
- `.desktop` 文件（含自启项）
- `cargo deb` 打包
- 启动自启目录写入 `~/.config/autostart/`

## 五、关键风险点

| 风险 | 应对 |
|---|---|
| Slint 列表混合 Block 渲染 | 用 `if` 分支分别渲染 TextInput / TodoItem，通过 model 分发 |
| Wayland 下托盘兼容 | 用 `tray-icon` 的 StatusNotifierItem；Deepin V23 默认 Wayland，需实测 |
| Wayland 下全局热键受限 | `global-hotkey` 在 Wayland 可能失效，降级为应用内快捷键 + 托盘快捷入口 |
| DDE 主题检测 | 通过 `gsettings get org.gnome.desktop.interface color-scheme` 或 DDE dconf 键监听 |
| 防抖保存 | 内容变化后启动 500ms 计时器，期间再次变化则重置；退出时强制 flush |
